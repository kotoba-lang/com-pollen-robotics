# com-pollen-robotics

Clean-room, API-compatible actor for the **Pollen Robotics Reachy 2 developer
SDK**.

Scaffold. The implementation lands in three surfaces — a `.kotoba` schema,
`.cljk` decision cores, and a `.cljc` host — via pull request.
